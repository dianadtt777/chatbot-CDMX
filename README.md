# 𐙚‧₊˚📒✩ ₊˚☁️⊹♡ CDMX Actividades Chatbot 𐙚‧₊˚📒✩ ₊˚☁️⊹♡

Este es un chatbot interactivo basado en consola desarrollado en **Python**. Su objetivo es guiar a los usuarios a través de una serie de menús dinámicos para encontrar excelentes recomendaciones de comida, cultura y entretenimiento en la Ciudad de México.

## 🚀 Características
* 🍕 **Comida:** Recomendaciones de pizzas (estilo NY, Chicago, Napolitana), comida mexicana tradicional y restaurantes asiáticos con mapas o direcciones.
* 🏛️ **Museos:** Opciones interactivas para museos infantiles (como el Papalote) o contemporáneos (como el Franz Mayer con cálculo de descuentos para estudiantes).
* 🎵 **Música:** Consulta de próximos conciertos de pop y simulación de compra de boletos por zonas para eventos clásicos en el Auditorio Nacional.

## 🛠️ Cómo ejecutar el proyecto
Asegúrate de tener Python instalado en tu computadora. Abre la terminal y ejecuta:

```bash
python chatbot.py
```
